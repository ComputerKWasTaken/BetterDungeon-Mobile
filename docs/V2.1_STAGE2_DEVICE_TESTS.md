# V2.1 Stage 2 Device Gate

Run this checklist on an Android device before closing Stage 2. Use temporary
provider credentials and remove them after testing.

## Provider settings

- Open **Settings > Ultrascripts > AI** and confirm both provider cards render without horizontal overflow.
- Select OpenRouter, then select Custom endpoint; confirm the base URL changes only when expected.
- Confirm a non-HTTPS custom URL is rejected before saving.
- Save, clear, and re-save each provider key; confirm the saved key is never displayed.
- Switch the active provider and reopen Settings; confirm the choice persists.

## Query parity

- Run the existing Character Prefill AI action with Gemini and confirm a successful result.
- Repeat with an OpenAI-compatible provider and confirm the selected provider/model is used.
- Trigger an invalid key and rate-limit response for each provider; confirm the error remains actionable and provider-specific.

## Streaming and cancellation

- Start one Navigator-compatible streaming chat request with Gemini and confirm deltas arrive in order.
- Repeat with the OpenAI-compatible provider.
- Cancel each provider while text is streaming; confirm output stops promptly and no late completion appears.
- Background and foreground the app during a stream; confirm it either resumes safely or ends with a clear error.
- Navigate away from the adventure during a stream; confirm the native request is cancelled.

## Regression

- Confirm Ultrascripts `ai.query` still returns text and schema-backed JSON.
- Confirm WebFetch and native text-to-speech still operate after an AI request.
- Close and reopen the popup repeatedly while a provider is configured; confirm status refreshes from the main runtime.
- Inspect Logcat for uncaught bridge, JSON, Port, or native transport errors.
