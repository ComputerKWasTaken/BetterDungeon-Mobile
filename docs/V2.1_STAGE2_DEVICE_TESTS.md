# V2.1 Stage 2 Device Gate

Run this checklist on an Android device before closing Stage 2. Use temporary
service credentials and remove them after testing.

## Service profiles

- Open **Settings > Ultrascripts > AI** and confirm the single profile panel renders without horizontal overflow.
- Select Gemini, OpenRouter, and Custom; confirm official URLs are locked and only Custom is editable.
- Confirm a non-HTTPS custom URL is rejected before saving.
- Save, clear, and re-save each service key; confirm saved keys are never displayed.
- Confirm **Save & test** persists before testing and saving activates the selected service.
- Reopen Settings and confirm all three saved profiles remain while the active service persists.

## Query parity

- Run the existing Character Prefill AI action with Gemini and confirm a successful result.
- Repeat with OpenRouter or a remote Custom service and confirm the selected model is used.
- Confirm Gemini text and schema-backed JSON requests include thinking; repeat schema-backed JSON on a non-Gemini service.
- Trigger invalid credentials and rate limits; confirm errors remain actionable and service-specific.
- Confirm automatic Gemini mode steps down only after 429, while manual Gemini and other services never switch models.

## Streaming and cancellation

- Start one Navigator-compatible streaming chat request with Gemini and confirm deltas arrive in order.
- Repeat with OpenRouter or Custom.
- Cancel each service while text is streaming; confirm output stops promptly and no late completion appears.
- Background and foreground the app during a stream; confirm it either resumes safely or ends with a clear error.
- Navigate away from the adventure during a stream; confirm the native request is cancelled.
- Exercise Navigator read tools, parallel calls, and two sequential tool rounds on Gemini 3; confirm continuation succeeds without a missing thought-signature error.
- Exercise an approved mutation proposal and confirm the approval boundary and server read-back remain intact.

## Regression

- Confirm Ultrascripts `ai.query` still returns text and schema-backed JSON.
- Confirm WebFetch and native text-to-speech still operate after an AI request.
- Close and reopen the popup repeatedly while a service is configured; confirm status refreshes from the main runtime.
- Inspect Logcat for uncaught bridge, JSON, Port, or native transport errors.
