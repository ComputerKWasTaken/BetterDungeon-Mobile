# BetterDungeon Mobile V2.1 Port Matrix

This ledger tracks the Android port of desktop BetterDungeon V2.1. It compares
desktop commit `da43bd51dbd961f166ac29f8f25f45a13ac4ec4e` against the desktop
`2.0.2` tag, with Mobile commit
`1d014a41473679e96f000118da333908700d9f92` as the starting point.

The desktop implementation is the behavioral source of truth. A file marked
**Adapt** must preserve the Android WebView bridge, touch UI, native services,
or another intentional Mobile difference instead of being copied wholesale.

## Status legend

- **Complete**: V2.1 behavior is already present or was reconciled in Stage 1.
- **Implemented**: code and automated contract coverage are complete; physical-device verification remains.
- **Partial**: part of the desktop behavior exists, but later work is required.
- **Pending**: the V2.1 behavior is not yet available on Mobile.
- **Excluded**: intentionally desktop-only or not shipped by the Mobile app.
- **Release**: documentation or packaging work reserved for Stage 6.

## Stage gates

1. Shared defaults/contracts and this ledger are reconciled without changing later-stage behavior.
2. Gemini, OpenRouter, and Custom profiles work through the one compatible query/stream/cancellation backend on-device.
3. Navigator context, research tools, and persisted read-only conversation work on-device.
4. The prototype is replaced by the full-screen sheet, draggable launcher, settings, and Android Back behavior.
5. Every mutation remains proposal-only until direct approval, with conflict checks and server read-back.
6. All rows are closed, regressions pass, metadata becomes 2.1.0, and one signed release artifact is prepared.
