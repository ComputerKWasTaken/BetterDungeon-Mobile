# BetterDungeon Mobile V2.1 Release Checklist

This is the final release gate for BetterDungeon Mobile 2.1.0. Official APKs
are published from the primary BetterDungeon repository; this development
repository must not contain signing credentials or committed APKs.

## Metadata and release content

- Confirm `app/build.gradle.kts` contains `versionCode = 4` and `versionName = "2.1.0"`.
- Confirm BetterDungeon Settings displays `v2.1.0` from the native application manifest.
- Confirm the What's New switcher opens 2.1.0 by default and retains the Mobile-specific 2.0.2 and 2.0.0 history.
- Confirm the README, port matrix, and public release notes describe provider routing, Navigator's approval boundary, and Android-specific behavior accurately.

## Automated regression gate

Run every JavaScript contract:

```powershell
node tests/ai-transport-contract.test.js
node tests/navigator-contract.test.js
node tests/navigator-mobile-contract.test.js
node tests/navigator-mutation-contract.test.js
node tests/v2.1-release-contract.test.js
```

Then run Android unit tests and assemble both variants:

```powershell
./gradlew.bat testDebugUnitTest lintDebug lintRelease assembleDebug assembleRelease --offline --no-daemon --console=plain
```

The release build must complete without JavaScript syntax errors, test failures,
Gradle failures, or `git diff --check` errors.

## Signing

The production keystore, aliases, and passwords must remain outside this
repository. Use Android Studio's **Generate Signed Bundle / APK** flow or the
owner's approved external signing process. Do not substitute the Android debug
certificate for a public release: it prevents upgrades from builds signed by the
real production identity.

Name the final artifact `BetterDungeon-Mobile-v2.1.0.apk`. Verify it with the
Android SDK tools before distribution:

```powershell
apksigner verify --verbose --print-certs BetterDungeon-Mobile-v2.1.0.apk
apkanalyzer manifest version-name BetterDungeon-Mobile-v2.1.0.apk
apkanalyzer manifest version-code BetterDungeon-Mobile-v2.1.0.apk
Get-FileHash -Algorithm SHA256 BetterDungeon-Mobile-v2.1.0.apk
```

Expected metadata is version name `2.1.0`, version code `4`, application ID
`com.computerk.betterdungeon`, minimum SDK 27, and target SDK 36.

## Device smoke gate

- Install the signed APK over the previous production-signed release and confirm Android accepts it as an upgrade without removing app data.
- Launch on Android 8.1 or newer and confirm AI Dungeon loads, stored settings remain available, and the settings WebView communicates with gameplay.
- Complete the provider checks in `V2.1_STAGE2_DEVICE_TESTS.md`.
- Complete the Navigator UI checks in `V2.1_STAGE4_DEVICE_TESTS.md`.
- Complete the mutation checks in `V2.1_STAGE5_DEVICE_TESTS.md` using a disposable adventure.
- Confirm Navigator's launcher, sheet, transcript, and proposals do not duplicate after navigation, reload, background/foreground, or WebView reinjection.
- Inspect Logcat for uncaught bridge, provider, GraphQL, WebView, IME, and Android Back errors.

## Release handoff

- Record the final SHA-256 digest in the primary repository's release notes.
- Upload only the verified production-signed APK to the primary BetterDungeon release.
- Keep the unsigned release candidate and all signing material out of source control.
- Tag the source commit only after the production-signed artifact passes the device smoke gate.
